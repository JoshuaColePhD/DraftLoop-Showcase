# Security policy

This repository is a public showcase: recorded results, documentation, and standalone analysis scripts. It contains no application backend, credentials, or student data.

## Reporting a vulnerability

Please report suspected vulnerabilities or accidentally exposed data privately through GitHub's [private vulnerability reporting](../../security/advisories/new) or by email to joshuacolephd@gmail.com. Please do not open a public issue for security reports. I aim to acknowledge reports within five business days.
