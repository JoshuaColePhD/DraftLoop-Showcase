Applied AI for classroom writing

Feedback becomes a next revision.

A student drafts an argument, inspects the rubric, and chooses a specific move to strengthen the next paragraph.

Recorded demonstration. This guide makes no model calls. The screenshot is from the actual local app using original synthetic writing. Its 5/6 score is unvalidated and is not part of the three-essay evaluation.

01 / DRAFT

Make an argument

The example argues that a selfie can preserve a shared memory. The writer supplies a claim, an example, and a qualification.

Read the workflow detail

The standalone coach uses a default prompt and analyzes the draft after editing. Prompt alignment is a heuristic aid; it should be checked by the writer.

02 / INSPECT

Read the rubric

The recorded screen shows thesis 1/1, evidence/commentary 3/4, and sophistication 1/1.

What the score does and does not show

These values come from a model proposal plus Python scoring rules. No human scored this synthetic draft. A complete response can still assign an incorrect score.

03 / REVISE

Choose a next move

The coach directs attention to the line of reasoning and offers a sentence to consider.

Read the captured suggestion

“This paragraph argues that selfies can record who was present and how they felt at a specific time.” A student should assess whether this adds reasoning or merely restates the paragraph. Generated advice is a starting point for revision.
